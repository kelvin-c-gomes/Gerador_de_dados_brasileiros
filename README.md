# Gerador de Dados Brasileiros (Fake Data Generator)

Uma aplicação desktop desenvolvida em **Python** que gera dados pessoais e documentos brasileiros realistas para fins de testes e desenvolvimento. O projeto utiliza a biblioteca `Faker` para a geração dos dados, e o`Tkinter` para uma interface gráfica intuitiva.

## Funcionalidades

* **Filtro por Gênero:** Escolha entre gerar dados com nomes masculinos ou femininos.
* **Documentação Brasileira:** Geração de documentos válidos (simulados) como CPF e RG.
* **Dados Completos:** Retorna nome, idade, data de nascimento, telefone, e-mail e endereço fictícios.
* **Interface Amigável:** Interface gráfica limpa e direta criada com Tkinter, facilitando o uso sem necessidade de linha de comando.
---
## Tecnologias Utilizadas

* **[Python](https://www.python.org/):** Linguagem base do projeto.
* **[Tkinter](https://docs.python.org/3/library/tkinter.html):** Biblioteca padrão do Python para criação de interfaces gráficas (GUI).
* **[Faker](https://faker.readthedocs.io/):** Biblioteca para geração de dados falsos (configurada para a localização `pt_BR`).
